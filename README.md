## Initiation
Visit the ai-dating-site folder
#### Front End
> npm install
#### Backend 
> Visit the src/server
> initiate the backend server at "node \index.js"
#### Chat with AI-Avatars
> visit http://localhost:3000/chat/christina
> and chat with AI
#### Note -
> make sure you enable all the dependencies and put all the environment variables in the right place.
#### Initiation
> npm install
> npm start
#### Chat with AI-Avatars
> visit http://localhost:3000/chat/christina
> and chat with AI
#### Note -
> make sure you enable all the dependencies and put all the environment variables in the right place or else use vercel dev as the project is enabled and Launch on the internet through vercel.(https://vercel.com/docs/getting-started-with-vercel)
